# DEMHAT AI

Türkçe konuşan, sesle kontrol edilebilen kişisel yapay zekâ asistanı.

## Hedefler
- Doğal sesli iletişim
- İnternet olmadan temel komutlar
- Kalıcı hafıza
- Web araştırması
- Dosya ve görev yönetimi
- Ücretsiz ve açık kaynaklı altyapı

## İlke
Ücretli API veya kredi gerektiren hizmet kullanılmayacaktır.
Gerçekten çalışmayan özellikler çalışıyor gibi gösterilmeyecektir.
